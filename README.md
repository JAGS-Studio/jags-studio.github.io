# JAGS Studio website

The website of **JAGS Studio**, a solo indie developer making cute, colorful games for everyone.

**Live site:** https://jags-studio.github.io

## Games
- **Meltdown Defense**, a beach tower defense game. [Get it on Google Play](https://play.google.com/store/apps/details?id=com.jogs.meltdowndefense)

## Files
- `index.html` and `images/`: the website
- `app-ads.txt`: authorizes our AdMob account to sell ads in our apps ([IAB app-ads.txt](https://iabtechlab.com/ads-txt/))
